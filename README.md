# 🐝 Beecrowd Solutions

## 📌 Sobre
Este repositório foi criado para armazenar e compartilhar as minhas resoluções dos desafios de programação do [Beecrowd](https://www.beecrowd.com.br/) (antigo URI Online Judge). 

O objetivo principal aqui é documentar meu processo de aprendizado, aprimorar minha lógica de programação e explorar as particularidades de diferentes linguagens enquanto resolvo problemas de algoritmos, estruturas de dados, matemática, entre outros.

## 🚀 Tecnologias e Linguagens Utilizadas
Neste repositório, você encontrará soluções desenvolvidas em:
* **C** 💻
* **C++** ⚙️
* **Python** 🐍
* **JavaScript** 💛
